# Hammond Plumbing Demo

A lightweight, mobile-first, single-file website prototype for a **hypothetical** residential plumbing contractor in Hammond, Louisiana.

**Live demo:** https://tmleblancjr.github.io/hammond-plumbing-demo/

## Demonstration safeguards
- The business name, phone number, and email are placeholders.
- Testimonials are illustrative, **not genuine customer reviews**.
- The example service-area list does **not** establish actual coverage.
- The demonstration is tagged `noindex, nofollow` to discourage indexing a nonexistent business.
- The estimate form only opens an email composer with a placeholder recipient. It does **not** deliver a request to a contractor or store submissions.
- Click-to-call is deliberately disabled on the demo until a real contractor's phone number is configured.

## Launch checklist for an actual customer
1. Obtain permission and accurate business name, contact information, service list, coverage, operating hours, and any verifiable licensing/credentials.
2. Replace placeholders throughout `index.html`; add a real `tel:` link for desktop and mobile.
3. Replace sample testimonials with properly authorized, authentic reviews (or remove them).
4. Connect the estimate form to a real service/backend with spam protection, consent/privacy disclosures, and email notifications. Test delivery before advertising it.
5. Remove the `noindex, nofollow` meta tag **only after** real information is added and the owner approves launch.
6. Add a custom domain, canonical URL, verified local-business details, and measurement tools with appropriate privacy practices.
7. Test on mobile and desktop, including keyboard navigation, tap-to-call, form delivery and performance.

## Editing and hosting
The website is contained in `index.html`, with inline CSS and JavaScript. GitHub Pages publishes from `main` at repository root. Editing the file and committing triggers a redeploy.

## Commercial use
Treat this as a portfolio concept, not a claimed operating plumbing business. Do not collect real leads until a contractor has authorized the funnel and provided working contact information.
